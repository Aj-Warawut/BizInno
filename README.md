# BizInno · สาขาวิชาบริหารธุรกิจและนวัตกรรมดิจิทัล มหาวิทยาลัยมหาสารคาม

หน้าเว็บของหลักสูตรบริหารธุรกิจมหาบัณฑิต (บธ.ม.) และปรัชญาดุษฎีบัณฑิต (ปร.ด.) สาขาวิชาบริหารธุรกิจและนวัตกรรมดิจิทัล

| หน้า | สำหรับ | ลิงก์ |
|---|---|---|
| `register.html` | นิสิต: แผนการลงทะเบียนเรียนภาคปัจจุบัน (ไทย/อังกฤษ) | https://aj-warawut.github.io/BizInno/register.html |
| `index.html` | ผู้ประเมินและหลักสูตร: ข้อมูลประกอบการประเมินคุณภาพระดับหลักสูตร | https://aj-warawut.github.io/BizInno/ |

ข้อมูลทั้งสองหน้ามาจากไฟล์ `bizinno_*.json` ชุดเดียวกัน สร้างจาก มคอ.2 มคอ.3 มคอ.7 และทะเบียนนิสิต (นับรวม ไม่มีข้อมูลระบุตัวบุคคล)

**อัปเดตทุกภาค:** ดับเบิลคลิก `อัปเดตหน้าAUN.command` ในคลังงานประกันคุณภาพ แล้ว push repo นี้ผ่าน GitHub Desktop
วันสำคัญ ลิงก์ลงทะเบียน และตารางเรียนของหน้านิสิต แก้ใน `bizinno_data.json` ส่วน `register`
